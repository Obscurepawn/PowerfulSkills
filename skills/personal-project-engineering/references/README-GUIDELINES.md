# README：让第一次使用有结果

开头用一两句话说明谁会在什么场景用这个项目、能得到什么。选一个能体现核心价值的小例子。命令行工具可以展示一条命令和一行有辨识度的输出。库可以展示一次导入、一次调用和返回值。服务则给出启动后能从外部观察到的响应。

1. 确定起点。用户拿到的是发布包、仓库副本，还是已经启动的服务？列出这条路径真正依赖的版本、输入文件或配置。按项目的清单与锁文件选工具。
2. 按执行顺序写出安装、运行和确认结果的步骤。若要切换目录，让下一条命令能直接跟着运行。输入用项目自带的小样本，或给出读者可以当场创建的内容。
3. 按文中的起点实际走一遍，对照输出或生成物。时间戳、机器路径等不稳定字段只写识别方法。缺少依赖时说明验证停在哪一步，别把推测的输出当作实测。

让快速开始靠前。用户能完成第一次操作之后，再给出配置说明、API、开发指南、求助渠道和许可证。只链接实际存在的资源，仓库内优先使用相对路径。新项目还没有发布包时，写已经能走通的源码路径。尚无可运行入口时，明确开发状态与可用内容。

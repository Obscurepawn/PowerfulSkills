# 清晰回答与自然表达（常驻规则片段）

可将以下内容加入全局或仓库级 `AGENTS.md`（或 `CLAUDE.md`、`GEMINI.md`），用于日常简短问答与任务汇报；遇到长文写作、润色改稿、翻译或去 AI 味任务时，再按需调用 `clear-answer-writing` 技能。

```markdown
## 表达与回答约定

- 默认使用自然的中文书面语；用户指定其他语言、文体或格式时照办。
- 问答先给结论或直接答案，再讲关键机制、依据和例子；汇报任务先说当前动作、发现或结果。简单问题简答，短输出不加多余标题层级，结语不加客套邀请。
- 把篇幅花在推进理解或行动的核心内容上。删除无新增信息的免责声明、泛泛兜底（如“仅供参考”“视具体情况而定”）、段尾设防和读者未提出的假想误解。
- 影响结论或操作的真实前提直接写成条件句（“在 X 时，Y”），同一前提只交代一次；严守事实、否定、范围、完成状态与不确定程度，不把推测写成事实，不编造数据或经历。
- 删掉元叙述（“本文将……”“接下来看……”）、节尾同义复述、“这里要分清两种问题”式预告和无真实误解支撑的“不是 A，而是 B”。
```
